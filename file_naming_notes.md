# File and folder naming requirements for the “Avtocellseek” pipeline

This document summarizes the expected folder structure and file naming conventions for the image analysis pipeline.

## 1. Folder structure

It is recommended to keep the main data folder inside a generic `Data` directory.

During processing the script will create an `Object_masks` subfolder containing the masks of detected cells (generated by `Object_maker.py`).

To start the pipeline you will need to provide the full path to the folder containing all TIFF images to be processed (this path can be copied from the file explorer).

Masks are saved as:

`{base_name}_ch01_mask.npy`

Example:

`19022025_Kv1-2_Ce4_Hg_G_0_1_z000_ch01_mask.npy`

## 2. Image file names

General naming pattern:

`{date}_{experiment}_{series}_{position}_z{slice}_ch{channel}.tif`

Example:

`19022025_Kv1-2_Ce4_Hg_G_0_1_z000_ch01.tif`

Rules:

- Use underscore `_` as the only separator between blocks.
- Channel suffixes:
  - `_ch00.tif` — green channel (fluorescent toxin: HgTx-GFP or Atto-HgTx).
  - `_ch01.tif` — red channel (mKate2–Kv1.1/1.2).
- `series` — numeric series index (e.g. `0`, `25`, `125`), automatically parsed from the file name.
- In automated Z‑stack acquisition, the series may be encoded in the Z‑index only; in that case the `z000` block is essential for correct parsing.

The scripts use these patterns to:

- group images belonging to the same experimental series,
- match red and green channels of the same field or time point.

## 3. Processing workflow (logic)

**Step 0: Folder path**

The program asks for the path to the folder with images. Paste the full path (e.g. `C:\Data\Kv1-1_1-2\Ce4_vs_HgTx_G\19022025`).

**Step 1: Object detection (Object_maker.py)**

- Goal: automatic creation of cell masks using a pre-trained Cellpose model.
- Only the red channel (`_ch01.tif`) is analyzed.
- Masks are saved to the `Object_masks` folder as `.npy` files.
- The module is run automatically if `Object_masks` does not exist or is empty.
- The console output lists detected series; check that they match your expectations (otherwise file names should be corrected).

**Step 2: Mask inspection**

- The user is shown random images with overlaid masks for visual inspection.
- If segmentation looks correct, close the window to proceed; the program continues automatically.

**Step 3: Interactive processing (cellpose_analysis.py)**

- The script asks: “Готовы начать пользовательскую обработку? (да/нет):”.
  - Answer `да` to continue; you may interrupt at this point if needed — masks will be preserved.
- Available series are listed in the console; you can choose the order of processing or skip already processed series (their results will be automatically included in the final file).

For each image in the selected series a window shows:

- the original image and its file name,
- overlaid masks (each cell in a unique color),
- a tool for cell selection by mouse click,
- counters for selected cells in the current image and total for the series.

Interaction:

- Single click on a cell: selects it (inner ring turns red).
- Second click on the same cell: deselects it.
- After selecting cells for all images in a series, results are saved to a CSV file.

## 4. Output files

- `cell_intensity_results_series_{N}.csv` — per‑series data.
- `cell_intensity_results_all_series.csv` — merged data for all processed series.

Columns:

- `image` — image file name,
- `cell_id` — cell identifier,
- `background_red`, `background_green` — background intensities,
- `red_intensity`, `green_intensity` — mean intensities in the cell mask,
- `ratio` — green/red intensity ratio,
- `series` — series index.

These CSV files can be analyzed in Excel, Python or R.

## 5. User checklist

**Before running the code:**

- Ensure that all images have correct channel suffixes (`_ch00.tif`, `_ch01.tif`).
- Series indices in file names should correspond to experimental conditions.

**Running the code:**

```bash
python Main_cellpose.py
```

- Provide the full path to the image folder when prompted.

**During processing:**

- On the mask inspection step, verify that cell boundaries are segmented correctly.
- During cell selection, click only on cells that should be included in quantitative analysis.
- Use the “Завершить выбор” control (if present in the GUI) to proceed to the next series.

**Analyzing results:**

- Open the final CSV files and use them to compute Rav, SEM, and fit binding curves.

## 6. Examples

Image file:

`19022025_Kv1-2_Ce4_Hg_G_5_1_z000_ch01.tif` — series 5, position 1, red channel.

Corresponding mask:

`Object_masks/19022025_Kv1-2_Ce4_Hg_G_5_1_z000_ch01_mask.npy`.

## 7. Important notes

- If masks or images do not load, first check file names and folder structure.
- Avoid spaces and special characters in folder and file names.
- Always provide a valid absolute path to the image folder when prompted.
